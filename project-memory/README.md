# Project Memory Vault

## Purpose
This is the repository native memory stack for local-first, safe, auditable operation.

## Structure
- `.projectmem/`: structured agent runtime memory
- `project-memory/`: Obsidian-compatible knowledge vault
- `.repo-plugins/`: enforceable operating policies
- `harness/`: reusable operation specification
- `.obsidian/`: local graph workspace state

## Operation Contract
1. Read memory before coding.
2. Read harness and repo plugin policies before execution.
3. Do no production writes by default.
4. Produce packetized handoff after each run.
