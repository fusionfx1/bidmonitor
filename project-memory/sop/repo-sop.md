# Repo SOP

## Before Work
1. Read `.projectmem/summary.md`
2. Read `.projectmem/current_state.md`
3. Read `.projectmem/safety_rules.md`
4. Read `harness/HARNESS_SPEC.md`
5. Read `.repo-plugins/plugin-manifest.json`

## During Work
- Keep diffs minimal
- Preserve account/customer/source scope
- No production mutations

## After Work
- Create handoff packet
- Include exact verification commands and results
- Update memory artifacts
