# Radio-style Memory Harness

This project follows the RadioSense operating pattern:

- memory-first before work
- isolated worktree for risky changes
- local-only implementation before deploy
- full handoff packet after each run
- owner approval before production actions
- test evidence required
- no silent scope expansion

## Required Memory Artifacts
- summary
- current state
- decision log
- safety rules
- agent runs
- latest handoff
- repo plugin manifest
